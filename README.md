# Thermal Pro Web

Web mo phong Thermal Pro co mat khau truy cap.

## Chay tren may

Mo file `start-web.bat`, sau do vao:

```txt
http://127.0.0.1:8080/
```

Mat khau mac dinh:

```txt
thermal2026
```

## Dua len hosting de co link public

Co the deploy project nay len Vercel thong qua GitHub.

Tren Vercel can dat bien moi truong:

```txt
WEB_PASSWORD=mat_khau_ban_muon
```

Sau khi deploy xong, Vercel se cap cho ban mot link public dang `https://ten-project.vercel.app`.
Ai co link va mat khau moi truy cap duoc.
